
## 一、 语言与风控约束（深度去除“AI味”）

   1. 词汇黑名单限制：严禁在文中出现以下高频 AI 词汇和抒情性/总结性过渡词：“总而言之”、“不可否认”、“值得一提的是”、“双刃剑”、“如前所述”、“正如……所说”、“让我们携手”、“砥砺前行”、“深远影响”、“蓝图”。
   2. 零情感客观笔触：行文必须保持绝对的客观、中立、克制和理性，严禁使用任何夸张、煽情、带有个人情绪色彩的修饰词或叹号。
   3. 动作精准化代替通用词：禁止滥用“抓好”、“搞好”、“大力推进”、“全面提升”等泛化词。涉及机制用“健全/理顺”，涉及责任用“压紧/压实”，涉及技术/平台用“搭建/构筑”，涉及痛点用“打通/疏通”，涉及资产用“盘活”。
   4. 拒绝无意义废话：每一句话都必须承载实质性的信息或逻辑论点。删除所有不影响核心原意的垫字、套话和机械式复述。

## 二、 内容与逻辑约束（防止信息灌水）

   1. 数据与事实锚定（禁止幻觉）：不要自行编造、虚构任何政策文件名、年份或具体数据。如果提供的原始素材中缺少核心成效数据，请统一使用 [具体数据] 或 [X个] 留白标注，严禁使用模糊的“大量”、“显著”、“众多”来应付。
   2. 逻辑层级递进：段落之间、分点之间必须具备严格的逻辑逻辑（如：从宏观到微观、从内部到外部、从体制机制到具体业务），严禁前后内容交叉穿插或逻辑断层。
   3. 小标题结构对仗：核心段落的并列小标题必须采用“动宾结构”或对称排比句式（例如：锚定核心引路、聚焦痛点攻坚、紧扣成效收尾），且字数必须严格对齐，以增强文章的节奏感和结构力量。
   4. 例证结合约束：每一个核心论点或举措之后，必须紧跟“做法阐述 + 典型事例/场景验证”的闭环逻辑，不能只抛出空洞的概念。
